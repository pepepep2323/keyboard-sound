Jak to vypadáWhat it looks like

Overlay sedí v rohu obrazovky přes hru. Zmáčknuté klávesy a tlačítka myši se rozsvítí, myš kliká skrz. The overlay sits in a corner of your screen, on top of your game. Pressed keys and mouse buttons glow, and clicks go straight through.

Zblízka: drží se W + A, Shift a levé tlačítko myši. Popisky kláves se přizpůsobí tvé klávesnici (třeba ě š č ř ž). Close-up: W + A, Shift and the left mouse button are held. Key labels follow your keyboard layout.

Jak to spustitHow to start

  1. Stáhni KeyboardSound.zip a rozbal ho (pravý klik → Extrahovat vše). Download KeyboardSound.zip and unzip it (right-click → Extract All).
  2. Dvakrát klikni na KeyboardSound.exe. Double-click KeyboardSound.exe. Když Windows napíše „Systém Windows ochránil váš počítač“, klikni na Další informace → Přesto spustit. Aplikace jen není placeně podepsaná, proto ji Windows zatím nezná. If Windows says “Windows protected your PC”, click More info → Run anyway. The app just isn't code-signed, so Windows doesn't know it yet.
  3. Hotovo. Vpravo dole u hodin se objeví ikona klávesnice, pravým klikem na ni najdeš nastavení. Done. A keyboard icon appears near the clock; right-click it for settings.

OvládáníControls

Ctrl + Alt + F11 Přesunout nebo zvětšit overlay: táhni myší, kolečkem měníš velikost, pravý klik otevře další možnosti. Znovu stiskni pro uložení. Move or resize the overlay: drag it, scroll to resize, right-click for options. Press again to save.
Ctrl + Alt + F12 Ukončit aplikaci.Quit the app.
Ikona u hodinTray icon Zapnout/vypnout zvuk, skrýt overlay, spouštět s Windows, ukončit. Sound on/off, hide overlay, start with Windows, quit.

Ve hrách je overlay vidět v režimu „okno bez okraje“, ne v exkluzivní celé obrazovce. In games the overlay shows in borderless / windowed fullscreen, not exclusive fullscreen.
