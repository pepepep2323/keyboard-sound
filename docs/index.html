Jak to spustitHow to start

  1. Stáhni KeyboardSound.zip a rozbal ho (pravý klik → Extrahovat vše). Download KeyboardSound.zip and unzip it (right-click → Extract All).
  2. Dvakrát klikni na KeyboardSound.exe. Double-click KeyboardSound.exe. Když Windows napíše „Systém Windows ochránil váš počítač“, klikni na Další informace → Přesto spustit. Aplikace jen není placeně podepsaná, proto ji Windows zatím nezná. If Windows says “Windows protected your PC”, click More info → Run anyway. The app just isn't code-signed, so Windows doesn't know it yet.
  3. Hotovo. Vpravo dole u hodin se objeví ikona klávesnice a pravým klikem na ni otevřeš menu. Done. A keyboard icon appears near the clock; right-click it to open the menu.

📋 Jak otevřít menuOpen the menu

  • Pravý klik na ikonu klávesnice vpravo dole u hodin.
  • Nevidíš ji? Klikni na šipku ^ vedle hodin.
  • V menu: widgety, zvuk, hlasitost kliků, efekt, barva, hudba, spouštění s Windows, nápověda, ukončení.
  • Right-click the keyboard icon near the clock (bottom right).
  • Can't see it? Click the ^ arrow next to the clock.
  • The menu has: widgets, sound, click volume, effect, color, music, start with Windows, help, quit.

↔️ Přesunutí a velikostMove and resize

  • Zmáčkni Ctrl+Alt+F11 (nebo menu → Přesunout).
  • Táhni každý widget zvlášť, kolečkem nad ním měníš jeho velikost.
  • Pravý klik na widget: jeho možnosti (numpad, barva kočky, text…), skrýt, průhlednost.
  • Znovu Ctrl+Alt+F11 = hotovo, všechno se uloží.
  • Text nebo obrázek přidáš v menu → Widgety → Přidat…
  • Press Ctrl+Alt+F11 (or menu → Move).
  • Drag each widget on its own, scroll over it to resize.
  • Right-click a widget: its options (numpad, cat color, text…), hide, opacity.
  • Ctrl+Alt+F11 again = done, everything is saved.
  • Add a text or an image in menu → Widgets → Add…

🔊 ZvukSound

  • Menu → Zvuk: zapnout/vypnout, Creamy 1/2/3, hlasitost.
  • Vlastní zvuk: menu → Zvuk → Nahrát vlastní zvuk… (wav, mp3, m4a, ogg, flac, wma). Použijí se první 2 sekundy a hlasitost se srovná.
  • Menu → Sound: on/off, Creamy 1/2/3, volume.
  • Your own sound: menu → Sound → Load your own sound… (wav, mp3, m4a, ogg, flac, wma). The first 2 seconds are used and the volume is matched.

🎵 Hudba (Spotify, YouTube…)Music (Spotify, YouTube…)

  • Ctrl+Alt+↓ přehrát / pauza, Ctrl+Alt+→ / ← další / předchozí.
  • Ctrl+Alt+Shift+→ / ← posune skladbu o 10 s (držením dál).
  • Ctrl+Alt+Shift+↑ / ↓ hlasitost hudby (nebo kolečko nad přehrávačem).
  • Přehrávač: klikni na tlačítka, lištu nebo reproduktor (ztlumit).
  • Reklamy ve Spotify se samy ztlumí (vypneš v menu → Hudba).
  • Změnit zkratky: menu → Hudba → Změnit zkratky → vyber akci a stiskni novou zkratku.
  • Ctrl+Alt+↓ play / pause, Ctrl+Alt+→ / ← next / previous.
  • Ctrl+Alt+Shift+→ / ← seeks 10 s (hold to keep going).
  • Ctrl+Alt+Shift+↑ / ↓ music volume (or the wheel over the player).
  • The player: click the buttons, the bar or the speaker (mute).
  • Spotify ads are muted automatically (turn off in menu → Music).
  • Change shortcuts: menu → Music → Change shortcuts → pick an action and press the new shortcut.

⏻ Skrytí a vypnutíHide and quit

  • Skrýt widgety: menu → Zobrazit widgety, nebo jednotlivě v menu → Widgety.
  • Vypnout: Ctrl+Alt+F12 nebo menu → Ukončit.
  • Spouštět s Windows: menu → Spouštět s Windows.
  • Hry: widgety jsou vidět v režimu „okno bez okraje“, ne v exkluzivní celé obrazovce. Zkratky na hudbu fungují vždy.
  • Hide widgets: menu → Show widgets, or one by one in menu → Widgets.
  • Quit: Ctrl+Alt+F12 or menu → Quit.
  • Start with Windows: menu → Start with Windows.
  • Games: widgets show in borderless / windowed fullscreen, not exclusive fullscreen. Music shortcuts always work.
